# 규칙.md — 데이터+AI 크리에이터 캠프 대학부 예선

## 대회 개요
- **대회명**: 데이터+AI 크리에이터 캠프 대학부 예선
- **문제**: 119 신고전화 음성 및 전사 데이터를 이용한 응급상황 인식
- **데이터셋**: AI-Hub "위급상황 음성/음향(고도화) - 119 지능형 신고접수 음성인식 데이터"
  - 구글 드라이브로 제공된 것만 사용 가능 (외부 데이터 추가 금지)

## 3개 미션
| 미션 | 내용 | 담당 |
|---|---|---|
| Mission 1 | 성별 분류 | B |

**Mission 3 증상 9개 클래스**: 고열 / 구토 / 두통 / 복통 / 어지러움 / 열상 / 오심 / 전신쇠약 / 호흡곤란

## 핵심 규칙 (반드시 준수)
1. **Training은 서울 데이터만 사용**
   - address 필드 기준으로 서울 데이터만 걸러서 학습에 사용해야 함
   - 서울 외 데이터가 학습에 섞이면 실격 사유
2. **Validation 데이터는 backprop(학습)에 사용 금지**
   - 평가 · 하이퍼파라미터 튜닝 · early stopping 용도로만 사용 가능
   - `loss.backward()` / `optimizer.step()` 경로에 Validation 데이터가 들어가면 실격
3. **Pretrained 오픈소스 모델 허용**
   - 단, **상용 API(GPT, Claude 등) 호출은 전면 금지** — 최종 제출 코드에 이런 호출이 포함되면 실격
4. **Pretrained weight / tokenizer / config는 로컬 경로 로딩으로 구성**
   - 채점 환경은 인터넷이 차단될 수 있음
   - 최초 1회만 다운로드해서 로컬에 캐시/저장 후, `from_pretrained(로컬경로)` 형태로 로딩하도록 코드 작성
5. **requirements.txt로 환경 재현 가능해야 함**
   - 사용한 라이브러리와 버전을 모두 명시

## 데이터 확보 관련 주의사항 (실전 경험 반영)
- 원본 데이터가 타인 소유 구글 드라이브 공유 폴더로 제공되는 경우, **공유가 예고 없이 끊길 수 있음**
- 확보 시 권장 순서:
  1. 웹(drive.google.com)에서 파일 단위로 "사본 만들기" → 본인 구글 드라이브 계정으로 즉시 백업 (서버 내부 복사라 가장 빠르고 안정적)
  2. 로컬 디스크로 zip 다운로드 또는 폴더 복사 (용량만큼 여유 공간 필요 — 최소 데이터 용량의 1.5~2배 여유 권장)
  3. 압축 해제 후 반드시 **손상/누락 검증** 수행:
     - `python utils/io.py` — wav/json 매칭 개수 확인 (짝 안 맞는 파일 리포트)
     - `python utils/audio_check.py` — wav 헤더 손상 여부 확인
     - json 파싱 실패 여부 확인 (깨진 라벨 파일 탐지)
