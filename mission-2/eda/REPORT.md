# Mission 2 — 데이터 구조·품질 EDA 결과

## 조사 범위

2026-09-17에 서울 지역 데이터 복사본의 Training 29,200통화와 공식 Validation 3,640통화를 전수 스캔한 [집계 결과](results/summary.json)다. JSON 구조·발화 라벨과 WAV 헤더를 검사했다. 원본 전체 파형의 청취·디코딩이나 사람 단위 분리 검사는 수행하지 않았다.

## 매칭과 발화 수

| 항목 | Training | 공식 Validation |
|---|---:|---:|
| WAV 파일 | 29,200 | 3,640 |
| JSON 파일 | 29,200 | 3,640 |
| 정상 JSON | 29,200 | 3,640 |
| 유효 발화 | 889,358 | 111,947 |
| `speaker=0` 119대원 | 427,161 | 53,845 |
| `speaker=1` 신고자 | 462,197 | 58,102 |

사용한 데이터 복사본에서는 WAV/JSON 누락, 중복 stem, JSON 파싱 오류, 발화 유효성 오류, WAV 헤더 오류가 집계되지 않았다. 각 split의 전체 WAV 헤더는 **8kHz·mono·16-bit PCM**으로 확인됐다. 이 결과가 다른 데이터 복사본이나 실제 오디오 내용까지 보증하지는 않는다.

## 발화 길이

| 역할 | Training 중앙값 | Validation 중앙값 | Validation 평균 |
|---|---:|---:|---:|
| 119대원 (`speaker=0`) | 1.402초 | 1.399초 | 1.819초 |
| 신고자 (`speaker=1`) | 1.490초 | 1.485초 | 2.115초 |

길이는 JSON의 `(endAt - startAt) / 1000`으로 계산했다. 모델은 발화 앞 **1.5초**만 사용하므로 그보다 긴 발화의 뒤쪽 정보는 버린다. 길이 자체는 분류기의 입력으로 사용하지 않는다.

## 모델링과 공개 범위

한 행을 한 발화로 처리하는 Mission 2 매니페스트에는 `startAt`, `endAt`, 학습 정답 `speaker`가 있고 `text`는 없다. Training/Validation은 제공된 폴더 단위로 나눴다. 데이터 EDA는 모델 성능 측정과 별개이며, Small-stem 90.25%의 근거는 [모델 결과 보고서](../smallstem_resnet18/results/REPORT.md)다.

공개한 `summary.json`은 집계값만 담는다. 통화별/발화별 행, 원본 파일명, WAV/JSON, 절대경로와 체크포인트는 공개하지 않는다. WAV 헤더가 정상이라는 사실은 무음·왜곡·중첩 발성이나 같은 인물의 반복 출현이 없다는 뜻이 아니다.
